# ◈ MindHack Security — Low-Cognitive-Load Cyber Lab

**MindHack Security** is a gamified, browser-based cybersecurity training platform engineered with **low-cognitive-load design principles**. Designed to reduce overwhelm and burnouts, it breaks down complex technical topics into 5-minute micro-learning modules covering **Linux, Python Automation, OSINT Reconnaissance, Networking, and Web Vulnerabilities**.

## 🚀 Key Features

* 💻 **Interactive Terminal Simulator:** Practise Linux commands (`ls`, `cat`, `grep`), execute Python automation scripts (`fetch_flag.py`), run Nmap network scans, and perform SQL injection attacks directly in the browser with smart command templates.
* 🌳 **Interactive Skill Tree:** A dynamic SVG-based knowledge graph that visually unlocks new nodes and sub-disciplines as you complete modules.
* 🧠 **Spaced Repetition & Flashcards:** Integrates Active Recall theory with a SuperMemo-inspired SM-2 algorithm. Completed labs automatically turn into 1-minute flashcards for long-term memory retention.
* 🤖 **AI Neuro-Mentor:** Embedded real-time assistance with Socratic hinting, task breakdown ("Break It Down"), jargon-free explanations, and a 60-second breathing pause to clear working memory.
* 🎮 **Gamification & Energy-Adaptive Goals:** Features an XP progression system, operator levels, streak safeguards, micro-badges, and customizable daily goals (*Low Energy 🌙*, *Stable ⛅*, *Hyperfocus ⚡*).
* 🎧 **Tactile Web Audio Engine:** Includes synthesized sound effects and focus-enhancing ambient background noise (*Lo-Fi* & *White Noise*) to mask external distractions.
* ◎ **Focus Mode:** One-click distraction-free workspace mode that hides non-essential UI elements during hands-on labs.

## 📚 Curriculum Roadmap

1. **Module 1: Linux Operating Environment** — Navigation, file permission mechanics, and log filtering (`grep`).
2. **Module 2: Python for Security & Automation** — Writing HTTP request scripts (`requests`) and automating web parsing.
3. **Module 3: OSINT & Network Reconnaissance** — Service version detection using Nmap (`nmap -sV`) and port scanning fundamentals.
4. **Module 4: Web Application Security** — Understanding authentication bypass mechanisms via SQL Injection (`' OR '1'='1`).

## 🛠️ Tech Stack

* **Frontend:** Clean Vanilla JavaScript (ES6+), Semantic HTML5, CSS3 Variables, Flexbox/Grid.
* **Audio:** Native Web Audio API (Synthesizers & Noise Generators).
* **Data Persistence:** LocalStorage API (State & Spaced Repetition deck stats).
* **Dependencies:** Zero external dependencies or heavy frameworks.
